# 🎁 Case Opening Bot

Telegram бот для открытия кейсов с реальными призами, подобный системе CS:GO.

## 🚀 Возможности

- **Современный веб-интерфейс** через Telegram WebApp
- **4 типа кейсов** с разной стоимостью и призами
- **Реальные призы**: Steam игры, компьютерное оборудование, подписки
- **Telegram Stars** для пополнения баланса
- **Анимированное открытие** кейсов
- **Система рарности** с цветовым кодированием
- **Админ-панель** для управления ботом
- **Статистика** для пользователей

## 📦 Установка и запуск

### Локальный запуск

1. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Настройте переменные окружения** в `.env` файле:
   ```env
   BOT_TOKEN=your_bot_token_here
   DATABASE_URL=sqlite:///case_bot.db
   WEB_APP_URL=https://your-railway-app.com
   ADMIN_USER_ID=your_telegram_id
   ```

3. **Запустите бота:**
   
   **Windows:**
   - Запустите `start.bat` или `start.ps1`
   
   **Linux/Mac:**
   ```bash
   python bot.py
   ```

### Развертывание на Railway

1. **Подключите GitHub репозиторий** к Railway
2. **Установите переменные окружения** в Railway dashboard
3. **Деплой произойдет автоматически**

## 💰 Экономика

- **Курс:** 1 рубль = 1 Telegram Star
- **Минимальное пополнение:** 100 ⭐
- **Максимальное пополнение:** 5000 ⭐
- **Выигрыш всегда больше стоимости кейса**

## 🛠️ Технический стек

- **Python 3.11+**
- **aiogram 3.4.1** - Telegram Bot API
- **FastAPI 0.104.1** - веб-сервер для WebApp
- **SQLAlchemy 2.0.23** - ORM для базы данных
- **PostgreSQL** - база данных (продакшен)
- **SQLite** - база данных (разработка)

## 📱 Команды бота

- `/start` - Запуск бота и главное меню
- `/admin` - Админ-панель (только для администраторов)
- `/stats` - Статистика пользователя

## 🔧 Администрирование

Админ-команды доступны пользователям, указанным в `ADMIN_USER_ID`:

- **📊 Статистика системы** - общая статистика бота
- **👥 Управление пользователями** - информация о пользователях
- **💰 Финансовая статистика** - доходы и расходы
- **📝 Логи системы** - просмотр последних событий

## 🚧 Разработка

Для разработки используется локальная SQLite база данных. В продакшене автоматически используется PostgreSQL от Railway.
